# Bengala Healthy — Sitio web

Sitio estático de 5 páginas para Bengala Healthy, barra de bebidas y alimentación saludable en Acapulco (Costa Azul y Bonfil).

## Páginas
- `index.html` — Inicio
- `bengala-nosotros.html` — Nosotros
- `bengala-menu.html` — Menú
- `bengala-promociones.html` — Promociones
- `bengala-contacto.html` — Contacto

## Stack
HTML + CSS puro (sin frameworks ni build step). Fuente Baloo 2 embebida como `@font-face` en base64, sin dependencias externas.

## Deploy
Sitio 100% estático — cualquier plataforma de hosting estático funciona sin configuración (Vercel, Netlify, GitHub Pages, etc.). No requiere build command ni output directory especial.
